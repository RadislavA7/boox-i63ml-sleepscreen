# Заставка для Onyx Boox i63ML Newton

Приложение для электронной книги **Onyx Boox i63ML Newton** (Android 2.3): ставит **свою картинку на экран сна** или показывает **обложку книги, которую вы сейчас читаете**, и убирает «призраки» старой страницы на заставке.

> **Требуется root.** Приложение один раз обращается к `su` (Superuser), чтобы создать ссылку `/data/misc/advt.png`. Обычному приложению писать в эту системную папку нельзя, поэтому на книге без root оно работать не будет. Как получить root на i63ML, здесь не описано.

**English summary.** A small app for the Onyx Boox i63ML Newton (Android 2.3.1) that sets a custom sleep screen image, or shows the cover of the book you are reading, and clears e-ink ghosting before the sleep screen is drawn. **Root (`su`) is required once** to create the symlink `/data/misc/advt.png`; the system partition is not modified. The user interface is in Russian. Download the APK from [Releases](../../releases), see [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) for the technical details.

## Что умеет

* **Своя картинка на экране сна.** Форматы JPG/JPEG, PNG, BMP, GIF (у GIF берётся первый кадр). Картинка приводится к виду заводских заставок (серый, 758×1024), перед установкой видно, как она будет выглядеть, есть переключатели «Обрезать по центру» и «Усилить контраст».
* **Обложка читаемой книги автоматически.** Приложение следит за базой Onyx и всегда держит на экране сна обложку последней открытой книги. Обложка берётся из самого файла: FB2, FB2.ZIP, EPUB, MOBI/AZW/AZW3/PRC (MOBI проверен только на искусственном файле). Если в файле обложки нет, берётся миниатюра Onyx, а если и её нет, рисуется карточка с названием и автором.
* **Название и автор из метаданных книги**, а не из имени файла: у книги с файлом `194022.fb2` на карточке будет настоящее название. Заглушки вроде «Unknown» отбрасываются; только если в книге ничего нет, название берётся из имени файла («Автор - Название.fb2» делится на части, а случайные имена вроде `eODaC3S7` заменяются на «Без названия»).
* **Очистка экрана перед заставкой.** При нажатии кнопки питания экран сначала мигает белым, и поэтому на заставке не проступают следы прежней страницы (особенно заметные на тёмных обложках). Можно отключить галочкой.
* **«Восстановить по умолчанию»** одной кнопкой возвращает заводские картинки с Ньютоном.

Система не меняется: файлы в `/system` не трогаются, загрузка не затрагивается. Единственное, что создаёт приложение, это символическая ссылка `/data/misc/advt.png`, на которую SurfaceFlinger смотрит перед рисованием заставки.

## Совместимость

Проверено на **Onyx Boox i63ML Newton** (`I63MLP_HD`), прошивка `e346d7e` (сборка 27.01.2016), Android 2.3.1, процессор Rockchip RK29, root через Superuser 2.3.1. На других моделях и прошивках не проверялось: способ опирается на то, что SurfaceFlinger этой прошивки берёт `/data/misc/advt.png`, если файл есть. Очистка экрана дополнительно использует `/dev/ebc`, утилиту `/system/bin/ioctl` и чтение системного журнала; на другой прошивке она может не заработать, тогда её можно отключить.

## Установка

1. Убедитесь, что на книге есть **root** (в списке приложений есть Superuser или другой менеджер `su`).
2. Скачайте `SleepScreen.apk` на странице [Releases](../../releases).
3. Установите на книгу: либо `adb install -r SleepScreen.apk`, либо скопируйте файл на книгу по USB и откройте его в файловом менеджере. При необходимости разрешите установку из неизвестных источников в настройках Android.
4. Запустите приложение «Заставка» (значок с луной).
5. При первой установке заставки (или первом включении обложки) Superuser спросит разрешение: нажмите **«Разрешить»** и отметьте **«Запомнить»**. Окно держится около 10 секунд, потом доступ отклоняется. Если не успели, просто повторите действие.

## Как пользоваться

**Своя картинка.** Положите картинки в папку `Screensaver` на книге (по USB), нажмите «Выбрать картинку…», выберите файл, посмотрите предпросмотр и нажмите «Установить заставку». Заставка действует сразу, перезагрузка не нужна. Усыпите книгу, чтобы увидеть.

**Обложка читаемой книги.** Отметьте «Показывать обложку книги, которую читаю». Дальше всё само: при смене книги, при включении и выключении экрана и раз в полчаса приложение обновляет заставку. Обновление занимает 3–6 секунд; если уснуть раньше, один раз покажется предыдущая обложка. Книга определяется по базе Onyx (последняя открытая в читалке, проверено с AlReader для Onyx).

**Очистка экрана.** Галочка «Очищать экран перед заставкой» включена по умолчанию. Работает, когда книгу усыпляют кнопкой питания (при засыпании по таймеру очистки нет: перед ним нечем «узнать заранее»).

**Вернуть заводское.** Кнопка «Восстановить по умолчанию». Если вы собираетесь удалить приложение, сначала нажмите её.

Одна картинка действует на сон, на выключение и на экран «нет питания» одновременно.

## Если что-то пошло не так

* **Белый экран и книга не включается.** Перезагрузите книгу: удерживайте кнопку питания, выберите «Выключить», затем включите снова. Затем в приложении снимите галочку «Очищать экран перед заставкой» и напишите об ошибке в Issues с описанием, что делали перед этим.
* **Заставка не меняется.** Проверьте, что Superuser разрешил приложению доступ («Запомнить»). Если в приложении был отказ, запустите действие ещё раз и успейте нажать «Разрешить».
* **Убрать всё вручную.** Нажмите «Восстановить по умолчанию». Если приложения уже нет, а заставка осталась, удалите ссылку с root-правами: `su -c "rm /data/misc/advt.png"`.
